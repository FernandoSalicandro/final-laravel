### 🎯 Pattern utilizzato (da video tutorial):

```php
// PATTERN CORRETTO (da screenshot):

$game = Game::findOrFail($id);

// Modifico i campi singolarmente
$game->title = $data['title'];
$game->description = $data['description'];
$game->genre_id = $data['genre_id'];

// Gestione immagine separata

    Storage::delete($game->image_url);
    $img_url = Storage::putFile("games", $data['image']);
    $game->image_url = $img_url;
}

$game->save();

// Sincronizza relazioni
$game->consoles()->sync($data['consoles'] ?? []);
```

### 📝 DETTAGLI METODI:

**index() - Lista giochi:**
- Eager Loading: `Game::with(['genre', 'consoles'])`
- Ordinamento: `orderBy('title', 'asc')`
- Paginazione: `paginate(20)`
- Conta totale: `Game::count()`

**create() - Form creazione:**
- Carica tutti i generi: `Genre::all()`
- Carica tutte le console: `Console::all()`
- Passa alla view: `compact('allGenres', 'allConsoles')`

**store() - Salvataggio:**
- Validazione completa dati
- Upload immagine con `Storage::putFile()`
- Creazione gioco: `Game::create()`
- Sincronizzazione console: `sync()`
- Redirect con messaggio successo

**show() - Dettagli:**
- Carica gioco con relazioni: `with(['genre', 'consoles'])`
- Usa `findOrFail()` per gestire 404
- Passa alla view: `compact('game')`

**edit() - Form modifica:**
- Carica gioco esistente con relazioni
- Carica generi e console per select/checkbox
- Pre-seleziona valori attuali

**update() - Aggiornamento:**
- Validazione dati
- Modifica campi singolarmente (pattern corretto)
- Gestione upload immagine (elimina vecchia + carica nuova)
- Usa `save()` dopo modifiche
- Sincronizza console con `sync()`

**destroy() - Eliminazione:**
- Elimina immagine: `Storage::delete()`
- **CRITICO:** Elimina PRIMA relazioni pivot: `$game->consoles()->detach()`
- Poi elimina il gioco: `$game->delete()`
- Redirect con messaggio

                    5. JAVASCRIPT - GESTIONE MODAL

📂 File: resources/js/Utils/showDeleteModal.js

```javascript
export function showDeleteModal() {
    const deleteModal = document.querySelector('.deleteAlert');
    
    if (!deleteModal) {
        console.warn('Modal .deleteAlert non trovato');
        return;
    }

    const confirmBtn = deleteModal.querySelector('[data-action="confirm"]');
    const cancelBtn = deleteModal.querySelector('[data-action="cancel"]');
    
    let currentForm = null;

    // Click su bottone delete → mostra modal
    document.querySelectorAll('.deleteBtn').forEach(btn => {
        btn.addEventListener('click', function(e) {
            e.preventDefault();
            currentForm = this.closest('form');
            deleteModal.classList.remove('hidden');
            deleteModal.classList.add('flex');
        });
    });

    // Conferma → submit form
    if (confirmBtn) {
        confirmBtn.addEventListener('click', function() {
            if (currentForm) {
                currentForm.submit();
            }
        });
    }

    // Annulla → chiudi modal
    if (cancelBtn) {
        cancelBtn.addEventListener('click', function() {
            closeModal();
        });
    }

    // Click fuori → chiudi modal
    deleteModal.addEventListener('click', function(e) {
        if (e.target === deleteModal) {
            closeModal();
        }
    });

    function closeModal() {
        deleteModal.classList.add('hidden');
        deleteModal.classList.remove('flex');
        currentForm = null;
    }
}
```

📂 File: resources/js/app.js

```javascript

    showDeleteModal();
});
```

================================================================================
                    7. PROBLEMI RISOLTI OGGI
================================================================================

❌ PROBLEMA 1: Update non funzionava
CAUSA: Usavo `$game->update($data)` senza `$fillable`
SOLUZIONE: Aggiunto `$fillable` nel Model + pattern corretto con assegnazioni singole

❌ PROBLEMA 2: Immagine non si aggiornava
CAUSA: Logica confusa con ternary operator
SOLUZIONE: Separato logica upload in if dedicato

❌ PROBLEMA 3: Validazione genre_id sbagliata
CAUSA: `exists:console,id` invece di `exists:genres,id`
SOLUZIONE: Corretto nome tabella nella validazione

❌ PROBLEMA 4: Eliminazione gioco crashava
CAUSA: Foreign key constraint - relazioni pivot non eliminate
SOLUZIONE: `$game->consoles()->detach()` prima di `$game->delete()`

❌ PROBLEMA 5: Checkbox console non pre-selezionati
CAUSA: Sintassi errata: `contains($id ? 'checked'` (parentesi nel posto sbagliato)
SOLUZIONE: `contains($id) ? 'checked' : ''`

❌ PROBLEMA 6: Pattern non standard
CAUSA: Usavo sintassi personale invece di pattern Laravel
SOLUZIONE: Adottato pattern da video tutorial (Storage::putFile, array_key_exists, etc.)

❌ PROBLEMA 7: Sidebar non responsive
CAUSA: Nessuna media query + overflow gestito male
SOLUZIONE: CSS Grid con breakpoints + overflow-y: auto su main

❌ PROBLEMA 8: Modal delete non funzionava
CAUSA: Bottoni senza data-action + form non catturato
SOLUZIONE: Aggiunto data attributes + logica currentForm

                    8. CONCETTI CHIAVE APPRESI

📚 ELOQUENT RELATIONSHIPS - attach, detach, sync:

```php
// attach() - AGGIUNGI senza rimuovere esistenti
$game->consoles()->attach([1, 2, 3]);

// detach() - RIMUOVI (specifici o tutti)
$game->consoles()->detach([1, 2]);  // Rimuovi 1 e 2
$game->consoles()->detach();        // Rimuovi tutti

// sync() - SINCRONIZZA (mantieni SOLO questi)
$game->consoles()->sync([1, 2, 3]);  // Rimuovi tutti tranne 1,2,3
```

**Quando usare:**
- `attach()`: Aggiungi console a un gioco esistente
- `detach()`: Rimuovi console da un gioco / Elimina prima di delete
- `sync()`: Form edit con checkbox (il più usato)


📚 STORAGE FACADE:

```php
// Upload
Storage::putFile('folder', $file);           // Disk default (public)
$file->store('folder', 'public');            // Disk specificato

// Delete
Storage::delete($path);                       // Disk default
Storage::disk('public')->delete($path);      // Disk specificato

// Check
Storage::exists($path);                       // Controlla esistenza
```


📚 VALIDAZIONE:

```php
$data = $request->validate([
    'title' => 'required|string|max:255',
    'description' => 'nullable|string',
    'genre_id' => 'required|exists:genres,id',  // Controlla FK
    'consoles' => 'nullable|array',
    'consoles.*' => 'exists:consoles,id',       // Valida ogni elemento
    'image' => 'nullable|image|mimes:jpeg,png,jpg,gif|max:2048',
]);
```
